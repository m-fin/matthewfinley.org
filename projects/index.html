SKYCHARGE

SKYCHARGE is a flying game. I am porting it to Xbox. That port is not a listing you can open yet, so this page does not pretend to have a store link or a trailer hosted here. The source repository is public, which is a different kind of link: you can read the project, and you still cannot download a finished Xbox build from this site.

I am keeping the description at that size on purpose. A flying game being ported to Xbox is the fact. Extra mechanics, a release window, and a publisher are not facts I am adding.
