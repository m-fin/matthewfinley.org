Music

sonicrift

sonicrift is my music project. The name is always written in lowercase, including in the title of this page, so the heading stays lowercase too. The place to listen is soundcloud.com/sonicrift.

A recent alto sax jam is hosted on this page, under the sonicrift name, so you can press play without leaving the site. I am not printing a full track list here. SoundCloud is the catalog, and the player farther down is SoundCloud's own embed of that profile. If the embed is blocked, the link above still opens the project. Code repositories that use the sonicrift name, when they are public, show up in the GitHub list on the projects page. I am not describing those repositories as a discography.

The rest of the site is games, an alarm clock, a C++ project, and notes. Music sits beside that work rather than inside a separate brand. If you want to support it, the support page is the same set of methods used for the games, and those methods stay off until the links are real.
