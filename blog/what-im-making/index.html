What I'm making

Four projects are far enough along to have names on the projects page. This note is the same list in paragraph form, with the line between "you can look at the source" and "you can play it" drawn where it actually is.

SKYCHARGE is a flying game. The active work I am willing to announce is a port to Xbox. The source repository is public at github.com/m-fin/skycharge. The port itself is not a public listing. If you open this site looking for an Xbox store link, you will not find one, and that is the current state rather than a broken button. When a playable build exists in public, the card will grow a real link and lose the coming-soon label.

DRIFTHOME is a 3D space-exploration game. Same split: the repository at github.com/m-fin/drifthome is the public artifact, and a playable build is coming soon. I like the project because it is a place to fly through, which is a different itch from SKYCHARGE even though both involve movement. I am not going to invent a backstory on a blog post to make the difference sound bigger than the repositories already are.

Jingle is an alarm clock. The public repository is jingle-ios. An alarm clock does not need a manifesto. It needs to make a noise at the right time. The store listing is coming soon, so the repository is the link and the install button is not.

Lake House Manager is the C++ project. Its link is github.com/m-fin/lake-house-manager. It is not a game and it is not an alarm. It is a manager, and the language is part of the description because that is how I refer to it: the C++ Lake House Manager. I am not hosting a build of it on this domain.

Around those four, the GitHub account m-fin has a longer public history. The projects page loads that list in your browser so I do not have to freeze it into HTML and then forget to update it. Forks are tucked behind a checkbox because a fork is not the same kind of claim as a repository I started. Descriptions in that list belong to the repositories. If one of them disagrees with a sentence on this site, the sentence on this site is the one I am standing behind for the four named projects, and the GitHub text is the repository's own.

Music is the other making. sonicrift stays lowercase and lives on SoundCloud. It is not one of the four cards, because it is not a software release, but it is part of the same habit: finish enough of a thing that another person can press play.
